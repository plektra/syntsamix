# Channel card sheet generators

The channel card sheets are generated by scripts and drawn like a person would draw them: real wires inside each circuit block, labels only between blocks and to other sheets. Edit a script and rebuild when a value changes (for example after the breadboard tests), instead of editing the sheet in KiCad.

Rebuilding **replaces the whole sheet**. Edits made by hand in KiCad are lost.

| Sheet | Drawing | Reference netlist |
|---|---|---|
| Input | `input_wired.py` | `reference/input.json` (frozen from the verified label-connected sheet with `make_reference.py Input input`) |
| Filter | `filter_wired.py` | `filter_build.py` (writes `build/filter.json`) |
| Level | `level_wired.py` | `level_build.py` (writes `build/level.json`) |
| Routing | `routing_wired.py` | `routing_build.py` (writes `build/routing.json`) |
| Meter | `meter_wired.py` | `meter_build.py` (writes `build/meter.json`) |
| Chain and power | `chain_wired.py` | `chain_build.py` (writes `build/chain.json`) |

The reference netlist is written separately from the drawing on purpose: `check_netlist.py` compares every pin of the drawn sheet with it, so a wiring mistake in a layout cannot slip through.

## Rebuild

`./rebuild_all.sh` regenerates every wired sheet, runs all post-processing and the netlist checks, and ERC. The steps for a single sheet:

From this folder. Needs KiCad 10, `uvx` and the `mcp` Python package; run `mcpcall.py` with the Python from the kicad-mcp-pro uv environment, which has it.

```sh
python3 level_build.py                          # reference netlist (skip for Input)
python3 level_wired.py                          # drawing -> build/calls_level_wired.json
python3 mcpcall.py build/calls_level_wired.json # sch_build_circuit through kicad-mcp-pro
python3 post_wired.py ../level.kicad_sch 2 build/level_wired_extra.json reference/level_title.json
python3 fix_paths.py
python3 check_netlist.py level.json             # must report 0 problems and no duplicate references
```

Use `filter` with power-reference prefix `1`, `input` with `0`, `routing` with `3`, `meter` with `4` and `chain` with `5` the same way. After adding a sheet, run `root_links.py`: it labels the root sheet pins that appear on more than one sheet, so outputs of one sheet reach inputs of another. Then run ERC on `channel-card.kicad_sch`.

## The scripts

- **`schlayout.py`:** reads pin positions from the KiCad symbol libraries (and `../../libs/syntsamix.kicad_sym`), places symbols, draws Manhattan wires between pins, and collects labels and power symbols. It also adds junctions.
- **`post_wired.py`:** after the build it:
  - renames temporary unit references (`U9<ref><unit>`, for example `U91042` = U104 unit 2, because the builder cannot place several units of one symbol);
  - prefixes power references per sheet;
  - renames the GNDA/GNDPWR ground symbols to the project nets AGND/PGND;
  - adds junctions, no-connect markers, the title block (`reference/<sheet>_title.json`) and DNP flags;
  - places reference and value text beside each part (`left_fields` in the title file puts it on the left).
- **`fix_paths.py`:** rewrites symbol instance paths to `/<root>/<sheet>`, sets the project name and gives each sheet a unique page number (`sch_create_sheet` numbers every new sheet page 2). Without it the KiCad app reports "An error was found when loading the schematic" and repairs the file itself.
- **`check_netlist.py`:** exports the card netlist and compares it pin by pin with the reference; also lists duplicate references across sheets, which ERC does not report.
- **`make_reference.py`:** freezes a sheet's current netlist and part fields into `reference/` before it is redrawn.

## Layout rules

- Keep pin 1 of resistors and capacitors where the reference netlist has it. Change the reference's pin order rather than rotating a part 180 degrees.
- Never end a wire on another wire, or on a pin, unless a connection is intended: KiCad connects them.
- Keep labels at wire ends. Keep two-pin parts at least about 10 mm apart on the same axis so their text does not collide.
- Multi-gang parts (the dual trim pot) are drawn as their own block with labels.
- Test pads: `Sheet.tp()` puts a bare pad on a short stub from a wire point; give it the net name as value and add it to the reference netlist. `post_wired.py` keeps `TP` references out of the BOM.
- Reference blocks per sheet: Input 1-99, Filter 101-199 (decoupling C191-C206), Level 201-299 (capacitors from C221), Routing 301-399, Meter 401-499, Chain and power 501-599. Power flags live only on the Chain and power sheet.
- KiCad files allow no comments; generated root items are marked by the uuid prefix `c0ffee00` instead.
